## ちなみに中身
まず最初に  
ベクトルって何？　→ Python のパッケージが勝手にやってくれるから大丈夫だよ　笑
1. ’extra_vocab_1000.txt’ から単語と分野ラベルを読み込む
2. 各単語を5種類の文型(単語一つでやるとが誤差が大きくなるから)に当てはめ、各モデルで埋め込みベクトルを作る
3. 「匿名」と「プライバシー」について、関連語と定義文からそれぞれ概念ベクトルを作る
4. 参照語の平均ベクトルを使って共通の偏りを補正し、概念への近さを計算する
5. 参照語のスコア分布を基準にz得点を求め、モデル間の傾向や分野別の違いを集計する
6. CSVファイルと、設定に応じて散布図を出力する
